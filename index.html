Web Application Prioritas Proyek Utama

SIGAP (Sistem Informasi Pengaduan Tindak Perundungan dan Kekerasan)

Platform Layanan Pelaporan Berbasis Web untuk Perlindungan Pelajar

Ringkasan & Urgensi Solusi (Overview & Problem)

Tindak perundungan di lingkungan institusi pendidikan kerap kali tidak tertangani secara optimal karena siswa merasa tidak memiliki media penyampaian yang aman dan terjamin kerahasiaannya. SIGAP dibangun untuk menjembatani masalah ini dengan menyediakan formulir pengaduan digital yang mudah diisi serta dasbor pemantauan status aduan bagi pengelola.

Solusi yang Diterapkan
  • Formulir berstruktur jelas dengan kolom kronologi dan bukti aduan.
  • Pemberian kode tiket unik untuk melacak tindak lanjut tanpa membuka data pribadi pelapor secara sembarangan.
  • Panel manajemen laporan untuk memverifikasi validitas informasi.
Peran Saya (My Role)

Frontend & Web Developer: Merancang desain visual di Figma, memetakan responsivitas form di halaman web, menyambungkan alur request PHP ke MySQL/PostgreSQL, serta memastikan lingkungan Docker siap pakai.

Teknologi & Lingkungan Pengembangan

PHP MySQL / PostgreSQL Figma Git Docker

Libfind (Website Perpustakaan Pintar)

Platform Penelusuran & Manajemen Katalog Pustaka

Ringkasan Masalah & Solusi

Pencarian koleksi pustaka secara fisik menyita banyak waktu jika perpustakaan tidak memiliki modul pencarian digital yang akurat dan responsif. Libfind menyediakan antarmuka pencarian cepat dengan kartu informasi koleksi buku, kategori tema, serta penunjuk status ketersediaan di rak.

Fitur-Fitur Utama
  • Pencarian buku secara real-time berdasarkan kata kunci atau penulis.
  • Filter kategori koleksi pustaka yang ramah pengguna.
  • Kartu informasi ketersediaan buku yang mudah dipahami.
Peran Saya (My Role)

Frontend & Web Developer: Mendesain antarmuka katalog di Figma, menyusun elemen visual responsif, mengintegrasikan query pencarian data buku dengan PHP dan basis data, serta mengelola kode di Git.

Teknologi yang Digunakan

PHP MySQL / PostgreSQL Figma Git
