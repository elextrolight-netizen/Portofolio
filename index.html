Project Utama

1. SIGAP (Sistem Informasi Pengaduan Tindak Perundungan dan Kekerasan)

Aplikasi Web Layanan Pengaduan Pelajar

Overview

Aplikasi web yang dirancang khusus untuk memfasilitasi pelaporan tindak perundungan (bullying) dan kekerasan di kalangan pelajar secara terpusat, aman, dan transparan.

Problem

Banyak korban atau saksi perundungan di lingkungan sekolah ragu melapor karena ketiadaan kanal pengaduan yang mudah diakses, terjaga privasinya, dan memiliki pencatatan status penanganan yang jelas.

Solution

Membangun antarmuka formulir pengaduan digital yang ramah pengguna bagi siswa serta sistem manajemen laporan yang tertata bagi pengelola sekolah untuk memantau status aduan.

Features

  • Formulir pengajuan aduan tindak perundungan yang mudah digunakan.
  • Pelacakan status penanganan laporan (misal: terkirim, diproses, selesai).
  • Panel antarmuka bagi pengelola untuk meninjau data aduan masuk.
Teknologi:
PHP MySQL / PostgreSQL Figma Git Docker
My Role: Frontend & Web Developer

Development Process

Merancang wireframe dan antarmuka alur pelaporan di Figma, mengimplementasikan antarmuka halaman web, mengintegrasikan formulir aduan ke basis data, serta mengelola versi kode menggunakan Git dan lingkungan Docker.

Result

Sistem berhasil diuji dan berfungsi untuk mengirimkan formulir laporan serta menampilkan riwayat aduan. [Jumlah pengguna aktif atau dampak metrik: Belum diisi].

2. Libfind (Website Perpustakaan Pintar)

Platform Pencarian & Pengelolaan Pustaka Digital

Overview

Website katalog perpustakaan pintar yang memudahkan pengguna mencari buku, melihat ketersediaan stok, dan mengakses informasi pustaka secara efisien.

Problem

Pencarian koleksi buku di perpustakaan sering kali memerlukan waktu lama jika katalog belum terdigitalisasi dengan tampilan yang informatif dan navigasi yang cepat.

Solution

Menyediakan antarmuka web pencarian buku yang intuitif, dilengkapi kartu informasi koleksi buku, kategori, dan status ketersediaan yang jelas.

Features

  • Pencarian koleksi buku berdasarkan judul dan kategori.
  • Halaman rincian informasi buku dan status ketersediaan.
  • Antarmuka katalog pustaka yang terorganisir dan bersih.
Teknologi:
PHP MySQL / PostgreSQL Figma Git
My Role: Frontend & Web Developer

Development Process

Membuat desain prototipe halaman katalog di Figma, menyusun tata letak antarmuka pencarian buku, menghubungkan tampilan ke basis data koleksi pustaka, dan mengelola alur pengerjaan dengan Git.

Result
